# Web Design Guidelines — revisión de interfaz

## Cuándo usar
Al crear o revisar pantallas, componentes, formularios, navegación y experiencias web.

## Revisión
- Jerarquía visual: títulos, contenido, acciones y estados.
- Consistencia: espaciado, tipografía, color, componentes y patrones.
- Accesibilidad: etiquetas, foco visible, navegación por teclado, contraste, textos alternativos y semántica.
- Formularios: etiquetas claras, errores próximos al campo, validación comprensible y prevención de pérdida de datos.
- Interacción: estados hover/focus/disabled/loading, feedback y prevención de dobles envíos.
- Responsive: tamaños pequeños, desbordamientos, densidad y controles táctiles.
- Rendimiento percibido: carga, skeletons y feedback durante operaciones lentas.

## Entrega
Lista de hallazgos con severidad, ubicación, impacto y recomendación. Distingue problemas observados de mejoras opcionales. Respeta el sistema de diseño existente y evita reescrituras visuales no solicitadas.
